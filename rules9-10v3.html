Rules 9-10

Rule 9

Error Recovery

Error messages should be expressed in plain language (no error codes), precisely indicate the problem, and constructively suggest a solution. These error messages should also be presented with visual treatments that will help users notice and recognize them.


If a user makes a mistake, the system should give clear, easy-to-understand information about what went wrong and how to fix it.

Rule 10

Help and Documentation

It’s best if the system doesn’t need any additional explanation. However, it may be necessary to provide documentation to help users understand how to complete their tasks.


Provide clear documentation: If users need help, there should be simple, searchable instructions available to guide them.
